## Task 1: Add Audio Level Publishing to SpeechRecognitionService

<action>
In `SpeechRecognitionService.swift`:

1. Add a new published property for audio power level:
```swift
var audioLevel: Float = 0.0  // 0.0 to 1.0 normalized
```

2. Update the `installTap` closure in `startListening()` to calculate audio power from the buffer:
```swift
inputNode.installTap(onBus: 0, bufferSize: 1024, format: recordingFormat) { [weak self] buffer, _ in
    self?.request?.append(buffer)
    
    // Calculate audio power for waveform
    guard let channelData = buffer.floatChannelData?[0] else { return }
    let frames = buffer.frameLength
    var sum: Float = 0
    for i in 0..<Int(frames) {
        sum += channelData[i] * channelData[i]
    }
    let rms = sqrt(sum / Float(frames))
    let avgPower = 20 * log10(max(rms, 0.000001))
    // Normalize: -60dB..0dB → 0.0..1.0
    let normalized = max(0, min(1, (avgPower + 60) / 60))
    DispatchQueue.main.async {
        self?.audioLevel = normalized
    }
}
```

3. Change silence timer interval from `3.0` to `2.0` in `resetSilenceTimer()`.

4. Reset `audioLevel = 0.0` in `stopListening()`.
</action>

<acceptance_criteria>
- SpeechRecognitionService.swift contains `var audioLevel: Float = 0.0`
- `installTap` closure contains `let rms = sqrt(sum / Float(frames))`
- `resetSilenceTimer` uses interval `2.0` instead of `3.0`
- `stopListening()` contains `audioLevel = 0.0`
</acceptance_criteria>
