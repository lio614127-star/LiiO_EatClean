# Plan 18-03: AI Output Validation & Minimal Re-ask

## Goal
Implement Layer 2 (post-validation) and Layer 3 (minimal re-ask) for both JSON meal outputs and free-text chat responses. When a violation is detected, the app either filters + replaces the violating item (JSON) or rewrites the response (free-text).

- LiiO_EatClean/Features/Meals/MealSuggestionViewModel.swift (meal suggestion flow)

- LiiO_EatClean/Services/FoodSafetyValidator.swift (validator from 18-01)

## Task 1: Add health validation to MealSuggestionViewModel

After AI returns meal suggestion JSON and it's parsed into food items:

1. Call `FoodSafetyValidator.shared.validateFoodItems(items, against: memory)` 
2. If violations found:
   - Remove violating items from the list
   - Build a minimal re-ask prompt:
     ```
     "Thay thế món '\(violatedName)' bằng một món khác phù hợp.
     Yêu cầu:
     - Khoảng \(calories) kcal
     - Không chứa: \(avoidFoods.joined(separator: ", "))
     - Phong cách: Việt Nam
     Trả về JSON duy nhất: {\"name\":\"...\",\"calories\":...,\"protein\":...,\"carbs\":...,\"fat\":...,\"servingSize\":1.0,\"mealType\":\"...\"}
     "
     ```
   - Call AIService with this minimal prompt
   - Replace the violating item with the new one
3. Set `healthSafetyApplied = true` to show the subtle badge
4. Max 1 re-ask attempt per violating item. If re-ask also violates, simply remove the item.

## Task 2: Add health validation to MealPlanViewModel

Same logic as Task 1, but for meal plan results:

1. After daily/weekly plan is parsed, validate all items
2. Only re-ask for EACH violating item individually (partial repair)
3. Re-ask prompt includes the mealType and approximate calorie target for that slot
4. Set `healthSafetyApplied = true`

## Task 3: Add free-text safety scanner to ChatViewModel

After AI streaming completes (in the final text assembly):

1. Call `FoodSafetyValidator.shared.scanFreeText(finalText, against: memory)`
2. If forbidden foods detected:
   - Send a minimal rewrite prompt to AI:
     ```
     "Viết lại câu sau nhưng thay '\(detectedFood)' bằng thực phẩm an toàn cho người \(conditions):
     \(originalText)"
     ```
   - Replace the message text with the rewritten version
   - Set `healthSafetyApplied = true`
3. If no violations: do nothing

## Task 4: Add healthSafetyApplied state

Add `var healthSafetyApplied: Bool = false` to:
- `MealSuggestionViewModel`
- `MealPlanViewModel`  
- `ChatViewModel`

This flag is used by UI components to show the subtle badge.

## Task 5: Add helper method to AIService

Add a lightweight method `func quickReask(prompt: String) async throws -> String` that:
- Uses the same API key infrastructure
- Sends a short, single-turn prompt
- Returns the response text directly
- Does NOT use streaming (faster for small re-asks)
</action>
