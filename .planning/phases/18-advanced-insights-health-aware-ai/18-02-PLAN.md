# Plan 18-02: ContextBuilder Health Safety Upgrade

## Goal
Upgrade ALL ContextBuilder strategies with ABSOLUTE RESTRICTION blocks, inject recommended foods for health conditions, and add the post-validation + minimal re-ask layer using FoodSafetyValidator.

<read_first>
- LiiO_EatClean/Features/AI/ContextBuilder.swift (full file — all strategies need upgrading)

- LiiO_EatClean/Resources/health_food_mapping.json (mapping from 18-01)
- LiiO_EatClean/Data/Models/UserProfileMemory.swift (memory model)
</read_first>

<action>
## Task 1: Add ABSOLUTE RESTRICTION block builder

Add a new private method `buildAbsoluteRestrictionBlock(_ memory: UserProfileMemory) -> String` in ContextBuilder:

```swift
private func buildAbsoluteRestrictionBlock(_ memory: UserProfileMemory) -> String {
    let validator = FoodSafetyValidator.shared
    let allAvoid = validator.getAllAvoidFoods(for: memory)
    
    guard !allAvoid.isEmpty else { return "" }
    
    var block = "\n\n[⛔ ABSOLUTE RESTRICTION — TUYỆT ĐỐI CẤM]\n"
    block += "NEVER suggest, recommend, or mention these foods:\n"
    for food in allAvoid {
        block += "- \(food)\n"
    }
    block += "\nViolating this restriction is FORBIDDEN. If unsure, DO NOT suggest the food.\n"
    
    return block
}
```

## Task 2: Add recommended foods injection

Add a new private method `buildRecommendedFoodsBlock(_ memory: UserProfileMemory) -> String`:

```swift
private func buildRecommendedFoodsBlock(_ memory: UserProfileMemory) -> String {
    let validator = FoodSafetyValidator.shared
    let recommended = validator.getRecommendedFoods(for: memory)
    
    guard !recommended.isEmpty else { return "" }
    
    var block = "\n\n[✅ Ưu tiên gợi ý — Thực phẩm tốt cho sức khoẻ người dùng]\n"
    block += "- \(recommended.joined(separator: ", "))\n"
    
    return block
}
```

## Task 3: Inject into ALL strategies

For each strategy method, add these calls BEFORE the response rules or output format section:

1. `buildChatContext()` — add `prompt += buildAbsoluteRestrictionBlock(memory)` and `prompt += buildRecommendedFoodsBlock(memory)` after `buildMemoryBlock`
2. `buildMealSuggestionContext()` — REPLACE existing `avoidFoods` block with `buildAbsoluteRestrictionBlock(memory)`, add `buildRecommendedFoodsBlock(memory)`
3. `buildMealPlanContext()` — REPLACE existing `allAvoid` block with `buildAbsoluteRestrictionBlock(memory)`, add `buildRecommendedFoodsBlock(memory)`
4. `buildHealthAdviceContext()` — add both blocks after health conditions detail
5. `buildDailySummaryContext()` — add `buildAbsoluteRestrictionBlock(memory)` (no recommended needed for summary)

## Task 4: Update buildMemoryBlock

In the existing `buildMemoryBlock()`, replace the simple `memory.healthConditions.map(\.name)` line with more detailed info including dietary notes from both conditions and JSON mapping.

## Task 5: Keep backward compatibility

Do NOT break any existing method signatures. The `buildSystemPrompt(for:strategy:remainingCalories:mealType:)` signature stays the same.
