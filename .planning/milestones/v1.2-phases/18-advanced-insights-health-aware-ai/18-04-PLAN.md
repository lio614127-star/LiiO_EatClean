# Plan 18-04: InsightDetector Expansion

## Goal
Extend InsightDetector with 2 new insight types: repeatedMeals (B + lite fuzzy normalize) and macroImbalance (flexible range). Upgrade severity system from 2-tier to 3-tier (.low / .medium / .high).

## Task 1: Upgrade InsightSeverity to 3 tiers

Replace the existing `InsightSeverity` enum:

```swift
enum InsightSeverity: Int, Comparable {
    case low = 0      // informational (repeated meals)
    case medium = 1   // attention needed (macro imbalance short-term, low water)
    case high = 2     // critical (severe imbalance + goal conflict, health violation)
    
    static func < (lhs: InsightSeverity, rhs: InsightSeverity) -> Bool {
        lhs.rawValue < rhs.rawValue
    }
}
```

Update existing insights to use the new severity:
- lowProtein 3-day → `.medium` (was `.warning`)
- lowProtein 7-day → `.high` (was `.alert`)
- skippedMeal → `.medium` (was `.alert`)
- calorieOverrun → `.medium` (was `.warning`)
- lowWater → `.low` (was `.alert`)

## Task 3: Implement Repeated Meals Detection (INSE-01)

Add a private method `detectRepeatedMeals(mealsByDay:last5DaysComps:) -> [DailyInsight]`:

1. **Normalize pipeline**: For each food item name:
   - `lowercased()`
   - `.folding(options: .diacriticInsensitive, locale: Locale(identifier: "vi"))` (bỏ dấu)
   - Remove stop words: `["phần", "vừa", "mini", "đặc biệt", "sốt", "cay", "xào", "chiên", "nướng", "luộc", "hấp", "rang", "kho"]`
   - Trim whitespace, collapse multiple spaces

2. **Count occurrences**: Group by normalizedName across 5-day rolling window

3. **Trigger**: If any normalizedName appears ≥3 times in 5 days:
   ```swift
   DailyInsight(
       type: .repeatedMeals,
       message: "Bạn đang ăn món \(originalName) khá thường xuyên tuần này. Thử đổi sang món khác để đa dạng dinh dưỡng nhé.",
       suggestion: "Thay \(originalName) bằng cá, bò, hoặc đậu phụ để cân bằng protein.",
       severity: .low
   )
   ```

4. Cap at 2 repeated meal insights max.

## Task 4: Implement Macro Imbalance Detection (INSE-02)

Add a private method `detectMacroImbalance(mealsByDay:last7DaysComps:) -> [DailyInsight]`:

1. **Calculate daily macro percentages**: For each day with data:
   ```swift
   let totalCals = max(protein * 4 + carbs * 4 + fat * 9, 1) // avoid divide-by-zero
   let proteinPct = (protein * 4) / totalCals * 100
   let carbsPct = (carbs * 4) / totalCals * 100
   let fatPct = (fat * 9) / totalCals * 100
   ```

2. **Flexible ranges** (only warn 5% beyond edge):
   - Protein: warn if < 15% or > 40%
   - Carbs: warn if < 30% or > 60%
   - Fat: warn if < 15% or > 40%

3. **Trigger**: If same macro out of range ≥3 consecutive days (from last3DaysComps):
   ```swift
   // Example for high fat:
   DailyInsight(
       type: .macroImbalance,
       message: "3 ngày gần đây lượng chất béo của bạn hơi cao (\(Int(avgFatPct))%). Hãy thử giảm món chiên hoặc nước sốt béo nhé.",
       suggestion: "Thay đồ chiên bằng hấp hoặc luộc, chọn thịt nạc thay thịt mỡ.",
       severity: .medium
   )
   ```

4. If imbalance persists ≥5 days → severity upgrades to `.high`

## Task 5: Integrate into main detectInsights()

Call both new detection methods in `detectInsights()`:

```swift
// After existing P6 (low water) detection:

// P7: Repeated meals (5-day window)
let last5DaysComps = Array(last7DaysComps.prefix(5))
insights.append(contentsOf: detectRepeatedMeals(mealsByDay: mealsByDay, last5DaysComps: last5DaysComps))

// P8: Macro imbalance (3-day consecutive)
insights.append(contentsOf: detectMacroImbalance(mealsByDay: mealsByDay, last7DaysComps: last7DaysComps))
```

Update sorting to use Comparable: `insights.sort { $0.severity > $1.severity }`

Increase insight cap from 3 to 5: `return Array(insights.prefix(5))`
