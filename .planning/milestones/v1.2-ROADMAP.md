## Phase Details

### Phase 15: AI Memory Hub & Personality
- **Focus:** Persistent global memory and AI tone customization.
- **Key Deliverables:** `AIMemoryRepository`, `PersonalityPicker`, `GuidedSetup`.
- **Outcome:** AI now remembers user constraints and responds in a consistent tone.

### Phase 16: API Infrastructure & Context Compression
- **Focus:** Performance and reliability of AI requests.
- **Key Deliverables:** `APIKeyManager` (Actor-based), `ContextCompression`.
- **Outcome:** Reliable multi-key rotation and token-efficient history tóm tắt.

### Phase 17: Voice Chat
- **Focus:** Natural communication via speech.
- **Key Deliverables:** `SpeechRecognitionService`, `WaveformView`, `VoiceRecordingSheet`.
- **Outcome:** Seamless voice-to-text integration in Chat.

### Phase 18: Advanced Insights & Health-Aware AI
- **Focus:** Safety and proactive health guidance.
- **Key Deliverables:** `FoodSafetyValidator`, `HealthFoodMapping`, `InsightDetector` expansion.
- **Outcome:** AI strictly avoids forbidden foods and detects nutritional imbalances.

### Phase 19: Offline Mode & Custom Foods
- **Focus:** Local-first reliability.
- **Key Deliverables:** `NetworkMonitor`, `CustomFoodBuilder`, `PendingChatQueue`.
- **Outcome:** App remains functional without internet; users can create personal food items.

### Phase 20: Pro Chart UX & Data Visualization
- **Focus:** Professional data insights.
- **Key Deliverables:** 3-month view, smart axis labeling, revitalized weight charts.
- **Outcome:** High-fidelity visualization of long-term health trends.

## Milestone Summary

### Key Accomplishments
1. **AI Deep Context:** Moved from transient memory to a persistent, searchable AI Memory Hub.
2. **Health Guardrails:** Implemented a multi-layered safety system (Prompting + Validation + UI Rewriting).
3. **Local-First Architecture:** Successfully transitioned to a model where the app gracefully handles offline states.
4. **Professional UI:** Achieved premium chart aesthetics matching top-tier health apps.

### Major Decisions
- **Consolidated Insights:** Decided to move all health insights inside the `DailySummaryCard` to keep the Home screen focused on logging.
- **Parallel Requests:** Implemented parallel API key testing to reduce latency in complex planning tasks.
- **On-Device Voice:** Prioritized Apple's on-device speech recognition for privacy and speed.

### Tech Debt
- All critical UAT bugs (Phase 16 JSON rendering, Phase 20 labeling) have been resolved before completion.
